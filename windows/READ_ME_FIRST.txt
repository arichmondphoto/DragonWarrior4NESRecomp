Dragon Warrior IV for Windows - version @VERSION@
==================================================

A native Windows version of Dragon Warrior IV (NES), with HD graphics.
The game itself is NOT included: you need your own ROM file of
Dragon Warrior IV (USA) for the NES (a .nes file).

Requirements: 64-bit Windows 10 or 11 and a graphics card with OpenGL
(any PC from the last ten years).


1. Install
----------
Unzip the download (right-click > Extract All...) and put the
"Dragon Warrior IV" folder somewhere you can write to - Documents, the
Desktop or a games folder. Not in "Program Files": the game keeps your
saves and settings in its own folder.

Double-click DragonWarrior4.exe to start.

Windows may say "Windows protected your PC", because the program isn't
signed by a known publisher. Click "More info", then "Run anyway". It
asks only the first time.


2. Add your ROM
---------------
The launcher opens. Click "Browse For ROM" and choose your
Dragon Warrior IV (USA) .nes file. The launcher checks that it is the
right game and remembers it, so you only do this once. Then press PLAY.


Playing
-------
Keyboard: arrow keys = D-pad, Z = A, X = B, Enter = Start, \ = Select.
Gamepads (Xbox, PlayStation, Switch and others) work out of the box;
change controls in the launcher.
Esc = menu, F7 = save states, F8 = rewind, Tab = fast-forward,
F11 = full screen.

HD graphics are switched on. To play with the original graphics, open
"Mods" in the launcher and turn the HD pack off.

Widescreen (16:9): the launcher's Display settings, or the in-game menu.

Cheats: the launcher's "Cheats" page takes Game Genie codes.


Your saves and settings
-----------------------
Everything is kept in the game's folder, beside DragonWarrior4.exe:
the game's save (its three adventure logs) is a .sav file named after
your ROM file; save states are in "saves", settings in config.ini and
cheats in cheats.txt.

To update to a new version, copy your .sav file, the "saves" folder and
config.ini into the new version's folder. Back them up to keep your
progress safe.


If it doesn't start
-------------------
- "Windows protected your PC": More info > Run anyway (see Install).
- A message that a DLL is missing: keep every file of the folder
  together - the .exe needs the .dll files beside it.
- The game opens but saves don't stick: the folder is somewhere Windows
  doesn't let programs write (such as Program Files). Move it to
  Documents.
- Very old or virtual-machine graphics may lack OpenGL: update the
  graphics driver.
