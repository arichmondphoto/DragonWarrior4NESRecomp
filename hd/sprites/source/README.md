# Character art (owner's, generated with tools/openai_sprites.py)

One 1536x1024 sheet per character in the tools/export_chatgpt_sprites.py layout
(4 directions x 2 steps). Check/fit with tools/check_ai_sprites.py.

- C069-C072.png: the large demon (C069-C072 are its four quarters), drawn as
  one picture with its two poses; the checker cuts it into the quarters.
- C044.png: every frame of C044 is the same 8x8 tile four times, so the sheet
  is one cloud from the generated C044_ai_cloud.png tiled 2x2.
- log.jsonl: API usage and cost of every request.
